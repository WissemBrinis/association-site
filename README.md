# Next.js + Tailwind + Tailwindcss-rtl + Multi-language Arabic Support

This is an example for creating a quick Next.js app with RTL support for Arabic and other RTL languages, along with support for Tailwind CSS, a great open source CSS framework.

**Author**: Thamer H. (GitHub: [thamerh](https://github.com/thamerh))

- [Tailwind CSS](https://tailwindcss.com/)
- Original example: [Next.js + Tailwind CSS Example](https://github.com/vercel/next.js/tree/canary/examples/with-tailwindcss)

## How to Use

This project can be bootstrapped as an example with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app) using either npm or Yarn:

```bash
npx create-next-app --example https://github.com/thamerh/nextjs-tailwind-rtl-multilanguage-starter
# or
yarn create next-app --example https://github.com/thamerh/nextjs-tailwind-rtl-multilanguage-starter
